        In LM Studio, load a model and start its local server on port 1234. Local document extraction supports .txt, .md, .tex, and .docx.

        The hosted site cannot reach an AI API on your computer. To use LM Studio, run a local copy of Jobist on that same computer.

        1. Open the Jobist project folder on your computer.
        2. In LM Studio, load a model and start its local server on port 1234.
        3. On a Mac, double-click Start Jobist.command in that folder. Or run python3 server.py, then open localhost:8080.

        About Jobist

        Built for clarity and control

        Jobist uses the AI service you connect to read career documents, compare your evidence with a role, and draft application materials.

        It does not apply for jobs, contact employers, or let a model add unconfirmed facts to your profile.
